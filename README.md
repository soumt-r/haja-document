# 하자(Haja) 공식 문서 & 플레이그라운드

안녕하세요! 한국어 기반 스크립트 언어 '하자(Haja)'의 공식 튜토리얼 문서와 웹 플레이그라운드를 제공하는 저장소예요.

**하자(Haja)가 무엇인가요?**
하자는 "코딩하자, 우리말로 쉽게!"를 목표로 만들어진 프로그래밍 언어예요. 
영어나 기호 중심의 복잡한 문법 대신, 한국어의 자연스러운 문장 구조와 조사를 그대로 활용해서 코딩할 수 있도록 설계되었어요. 프로그래밍을 처음 접하는 사람도 마치 글을 읽고 쓰듯 쉽게 이해할 수 있는 것이 가장 큰 매력이랍니다.

이 웹사이트는 Astro와 TailwindCSS를 기반으로 만들어졌어요. 문서를 읽으면서 브라우저 위에서 즉석으로 하자 코드를 실행해 볼 수 있도록 CodeMirror 기반의 에디터를 내장해 두었어요.

특히 에디터 안에는 자체적으로 구현한 미니 LSP가 탑재되어 있어요. 코드를 치는 동안 실시간으로 문법 에러를 짚어주고, 작성 중인 변수명이나 메서드를 동적으로 추천해 주는 똑똑한 자동완성 기능도 함께 경험해 보실 수 있어요.

## 로컬에서 직접 실행해 보려면?

```bash
# 패키지들을 설치해요
npm install

# 로컬 개발 서버를 열어요 (http://localhost:4321)
npm run dev

# 정적 사이트로 완성해요
npm run build
```

## 폴더 구조는 이렇게 되어 있어요

- `src/pages/docs/`: 하자의 기본 문법과 객체지향 튜토리얼, 기술 명세서가 담긴 마크다운 파일들이 모여있어요.
- `src/pages/playground.astro`: 문서를 벗어나 조금 더 넓은 화면에서 마음껏 코딩해 볼 수 있는 메인 플레이그라운드 페이지예요.
- `src/utils/haja/`: 하자 언어의 핵심 엔진(렉서, 파서, 인터프리터) 구현체예요. 이 엔진이 브라우저에서 직접 동작하며 코드를 실행해 줘요.
- `src/utils/haja/hajaLSP.ts`: 에디터와 엔진을 연결해서 자동완성 및 문법 검사(Linting)를 돕는 파일이에요.
