**Hana**는 하자(Haja)와 카나데(Kanade)를 내 컴퓨터에서 실행하는 프로그램이에요. 이 문서의 실행 버튼과 플레이그라운드는 브라우저 안에서 도는 엔진이라 컴퓨터의 파일이나 네트워크에 손댈 수 없지만, Hana는 터미널에서 실행하는 프로그램이라 그런 일도 할 수 있어요. 그래서 이 문서에서 "브라우저에서는 쓸 수 없어요"라고 하는 도구는 모두 Hana 런타임으로 실행할 때 쓰는 것들이에요.

Hana는 Go로 만들어졌고, 인터프리터, 바이트코드 컴파일러와 VM, 명령줄 도구, 언어 서버가 실행 파일 하나에 들어 있어요. 소스 코드는 [github.com/soumt-r/hana](https://github.com/soumt-r/hana)에 있고, MIT 라이선스로 공개되어 있어요.

### 할 수 있는 일

| 명령 | 하는 일 |
| --- | --- |
| `hana run 파일.hj` | 하자(`.hj`), 카나데(`.knd`), 컴파일된 바이트코드(`.hn`)를 실행해요 |
| `hana build 파일.hj` | 바이트코드(`.hn`)로 컴파일해서 저장해요 |
| `hana pack 파일.hj` | 프로그램을 실행 파일 하나로 묶어요. 다른 운영체제용도 만들 수 있어요 |
| `hana init 폴더` | 시작 파일이 있는 새 프로젝트를 만들어요 |
| `hana lsp` | 에디터에서 자동완성과 오류 표시를 해 주는 언어 서버를 실행해요 |

`hana run`에 `--bc`를 붙이면 바이트코드 컴파일러와 VM으로 실행하고, 붙이지 않으면 트리워킹 인터프리터로 실행해요. 두 방식은 같은 결과를 내도록 만들어져 있어요.

### 브라우저에서 못 하는 일을 하는 도구

| 도구 | 하는 일 |
| --- | --- |
| [파일 다루기](/docs/hana/files) | `[파일]` 모듈로 파일과 폴더를 읽고 써요 |
| [소켓으로 대화하기](/docs/hana/sockets) | `[소켓]` 모듈로 네트워크로 글을 주고받아요 |
| [웹 주소에서 가져오기](/docs/hana/http) | `[HTTP]` 모듈로 웹 서버에 요청을 보내요 |
| [시간대](/docs/hana/timezone) | `timezone` 패키지로 도시마다 다른 시각을 다뤄요 |

`[수학]`, `[텍스트]`, `[경로]` 같은 나머지 표준 모듈은 브라우저에서도, Hana에서도 똑같이 돌아가요. 이 도구들은 [기본 문법 튜토리얼](/docs/tutorial/10-stdlib)에 있어요.

### 믿을 수 없는 스크립트를 돌릴 때

Hana는 기본으로 파일과 네트워크 접근을 허용해요. 남이 준 스크립트를 돌릴 때는 `--allow-file=false`로 파일 접근을, `--allow-net=false`로 네트워크 접근을 막을 수 있어요. 자세한 내용은 [파일 다루기](/docs/hana/files)와 [소켓으로 대화하기](/docs/hana/sockets)의 마지막 절에 있어요.

### 오류와 도움말도 내 언어로

Hana가 알려 주는 도움말과 오류 문구는 한국어와 일본어로 나와요. 스크립트가 낸 오류는 그 스크립트의 언어(하자는 한국어, 카나데는 일본어)로 나오고, 명령줄의 도움말은 `--locale ko`나 `--locale ja`, 환경 변수 `HANA_LANG`, 시스템 언어 순으로 정해져요.
