---

"만약 비가 오면 우산을 쓰고, 눈이 오면 패딩을 입자." 처럼 특정 조건에 따라 다른 코드를 실행하는 방법이에요.
가장 기본적인 '만약'을 사용해볼까요?

```haja
'속도'를 [숫자]인 120으로 정하자

만약 ('속도'가 100보다 크다) 라면:
    "너무 빠릅니다! 속도를 줄이세요."를 출력하자
```

이번엔 조건이 여러 개일 때를 살펴볼게요. `그렇지 않고 만약`을 사용하면 또 다른 조건을 검사할 수 있어요.

```haja
'점수'를 [숫자]인 85로 정하자

만약 ('점수'가 90보다 크다) 라면:
    "참 잘했어요!"를 출력하자
그렇지 않고 만약 ('점수'가 80보다 크다) 라면:
    "조금만 더 노력해봐요!"를 출력하자
```

모든 조건에 맞지 않을 때 기본적으로 실행할 코드는 `그렇지 않다면`에 적어주면 된답니다.

```haja
'나이'를 [숫자]인 15로 정하자

만약 ('나이'가 19 이상이다) 라면:
    "성인입니다."를 출력하자
그렇지 않다면:
    "미성년자입니다."를 출력하자
```
