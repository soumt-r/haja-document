"만약 비가 오면 우산을 쓰고, 눈이 오면 패딩을 입자." 처럼 특정 조건에 따라 다른 코드를 실행하는 방법이에요.
가장 기본적인 '만약'을 사용해볼까요? 비교문은 괄호 `()` 안에 넣는 것을 추천해요!

```hari
'속도'를 [숫자]인 120으로 정하자

만약 ('속도'가 100보다 크다) 라면:
    "너무 빠릅니다! 속도를 줄이세요."를 출력하자
```

이번엔 조건이 여러 개일 때를 살펴볼게요. `그렇지 않고 만약`을 사용하면 또 다른 조건을 검사할 수 있어요.

```hari
'점수'를 [숫자]인 85로 정하자

만약 ('점수'가 90보다 크다) 라면:
    "참 잘했어요!"를 출력하자
그렇지 않고 만약 ('점수'가 80보다 크다) 라면:
    "조금만 더 노력해봐요!"를 출력하자
```

모든 조건에 맞지 않을 때 기본적으로 실행할 코드는 `그렇지 않다면:`에 적어주면 된답니다.

```hari
'나이'를 [숫자]인 15로 정하자

만약 ('나이'가 19 이상이다) 라면:
    "성인입니다."를 출력하자
그렇지 않다면:
    "미성년자입니다."를 출력하자
```

### 여러 조건을 한 번에 검사하기 (그리고, 또는)

조건이 여러 개일 때는 `그리고`와 `또는`을 사용해서 한 번에 묶어서 검사할 수 있어요!
이때 **각 조건은 반드시 개별적으로 괄호 `()`로 묶어주어야** 엔진이 정확하게 이해한답니다.

* **그리고**: 양쪽 조건이 모두 참일 때만 참이 돼요.
* **또는**: 양쪽 조건 중 하나라도 참이면 참이 돼요.

```hari
'나이'를 [숫자]인 25로 정하자

(참고) 나이가 20보다 크고, 30보다 작으면 20대겠죠?
만약 ('나이'가 20보다 크다) 그리고 ('나이'가 30보다 작다) 라면:
    "20대입니다!"를 출력하자
```

```hari
'날씨'를 [문자열]인 "비"로 정하자

만약 ('날씨'와 "비"가 같다) 또는 ('날씨'와 "눈"이 같다) 라면:
    "우산이 필요해요!"를 출력하자
```

### 조건에는 참이나 거짓만 쓸 수 있어요

`만약`, `동안 반복`, `그리고`, `또는`에는 `참`이나 `거짓`이 되는 식만 쓸 수 있어요. 숫자나 글자, `비어있음`을 그대로 넣으면 "0이면 거짓" 같은 규칙으로 넘어가지 않고 에러가 나요. 조건을 잘못 쓴 실수가 조용히 지나가지 않게 하려는 거예요.

```hari fail
'나이'를 [숫자]인 20으로 정하자

만약 ('나이') 라면:
    "성인이에요!"를 출력하자
```

원하는 검사를 비교로 분명히 써 주세요. 값이 비었는지는 `비어있음`과 비교하면 돼요.

```hari
'나이'를 [숫자]인 20으로 정하자
'별명'을 [문자열]인 비어있음으로 정하자

만약 ('나이' >= 20) 라면:
    "성인이에요!"를 출력하자
만약 ('별명'과 비어있음이 같다) 라면:
    "별명이 아직 없어요."를 출력하자
```
