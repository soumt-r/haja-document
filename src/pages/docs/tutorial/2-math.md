컴퓨터는 계산을 아주 잘하죠! 숫자 데이터를 가지고 사칙연산을 해볼 수 있어요.
먼저 두 숫자를 더해보는 아주 간단한 계산을 해볼까요?

```haja
'가'를 [숫자]인 10으로 정하자
'나'를 [숫자]인 20으로 정하자
'결과'를 [숫자]인 '가' + '나' 로 정하자

틀"10 더하기 20은 {'결과'} 입니다!"를 출력하자
```

변수에 저장된 숫자에 바로 값을 더하거나 뺄 수도 있어요.

```haja
'점수'를 [숫자]인 50으로 정하자
'점수'에 10을 더하자

틀"점수가 올랐어요! 현재 점수: {'점수'}"를 출력하자
```

이번에는 빼기를 해볼까요?

```haja
'체력'을 [숫자]인 100으로 정하자
'체력'에서 15를 빼자

틀"공격을 받았습니다. 남은 체력: {'체력'}"을 출력하자
```

### 곱하기, 나누기, 나머지, 그리고 계산 순서

`*`(곱하기), `/`(나누기), `%`(나머지)도 쓸 수 있어요. 한 식에 여러 연산이 있으면 **곱하기·나누기·나머지를 먼저** 계산하고, 더하기·빼기는 그다음에 해요. 학교에서 배운 순서 그대로예요. 같은 종류끼리는 왼쪽부터 차례로 해요. 먼저 계산하고 싶은 부분은 괄호로 묶으세요.

```haja
(2 + 3 * 4)를 출력하자
((2 + 3) * 4)를 출력하자
(10 - 4 / 2)를 출력하자
(100 / 10 / 5)를 출력하자
(7 % 4 + 1)를 출력하자
```

차례로 `14`, `20`, `8`, `2`, `4`가 나와요. `2 + 3 * 4`는 곱하기를 먼저 해서 `2 + 12`가 되고, `100 / 10 / 5`는 왼쪽부터 `10 / 5`가 돼요.
