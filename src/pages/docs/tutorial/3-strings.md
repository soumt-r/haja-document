문자열 안에 변수나 계산 결과를 넣고 싶다면 어떻게 할까요? 하자는 `틀""`이라는 템플릿을 제공해요.
중괄호 `{}` 안에 변수나 식을 넣으면 글자 사이에 쏙 들어간답니다.

```haja
'이름'을 [문자열]인 "손님"으로 정하자
틀"{'이름'}님, 안녕하세요!"를 출력하자
```

틀 안에는 숫자 같은 다른 타입의 변수도 자연스럽게 넣을 수 있어요. 아주 편리하죠?

```haja
'체력'을 [숫자]인 100으로 정하자
틀"현재 체력은 {'체력'}입니다!"를 출력하자
```

---

### 글자 더하기와 뽑아내기

문자열끼리 더하거나, 원하는 위치의 글자만 뽑아낼 수도 있어요.

```haja
'인사'를 [문자열]인 "안녕" + "하세요"로 정하자
'인사'에 "!"를 더하자
'인사'를 출력하자

'첫글자'를 [문자열]인 '인사'의 1번째로 정하자
틀"첫 번째 글자는 {'첫글자'}예요."를 출력하자
```

---

### 유용한 문자열 도구들

하자는 글자를 다루는 편리한 내장 기능들도 제공한답니다. `<자르기>`, `<바꾸기>`, `<분리하기>`, `<포함확인>`을 사용해 보세요!

```haja
'문장'을 "사과 배 사과"로 정하자

(참고) 1번째부터 2번째 글자까지 자르기
'조각'을 '문장'의 <자르기>(1, 2)로 정하자
틀"자른 결과: {'조각'}"을 출력하자

(참고) 글자를 다른 글자로 바꾸기
'바뀐문장'을 '문장'의 <바꾸기>("사과", "포도")로 정하자
틀"바뀐 결과: {'바뀐문장'}"을 출력하자

(참고) 글자를 쪼개서 목록으로 만들기
'목록'을 '문장'의 <분리하기>(" ")로 정하자
틀"첫 번째 단어는 {'목록'의 1번째}예요."를 출력하자

(참고) 특정 글자가 들어있는지 확인하기
만약 ('문장'의 <포함확인>("사과")) 라면:
    "사과가 들어있어요!"를 출력하자
```

### 이스케이프 문자

문자열 안에서 특수한 기능을 쓰거나 겹치는 기호를 쓰고 싶을 때는 역슬래시(`\`)를 활용하는 '이스케이프 문자'를 쓰면 돼요.

> 💡 **이스케이프(Escape) 문자란?**
> 문자열 안에서 특별한 기능을 수행하거나 화면에 직접 출력하기 힘든 기호를 표현할 때 사용하는 약속된 기호입니다. 주로 역슬래시(`\`)와 문자를 조합해서 사용해요.

자주 쓰는 이스케이프 문자는 다음과 같이 정리할 수 있어요:

* `\n` : 다음 줄로 넘어가기 (줄바꿈)
* `\t` : 일정한 간격 띄우기 (탭)
* `\"` : 문자열 안에서 큰따옴표(`"`) 기호 그 자체를 출력하기
* `\\` : 역슬래시(`\`) 기호 그 자체를 출력하기

```haja
틀"줄바꿈을 해볼까요?\n\"화이팅!\""을 출력하자
```

코드 중간에 설명을 달고 싶다면 메모(주석)를 남겨보세요. 메모는 실행되지 않아요!

```haja
(참고) 이것은 한 줄짜리 메모입니다. 메모는 컴퓨터가 무시해요!
"메모 테스트 완료!"를 출력하자
```

### 글자 수 세기

`'이름'의 '길이'`로 글자가 몇 개인지 알 수 있어요. 한글도, 이모지도 글자 하나로 세요.

```haja
'이름'을 [문자열]인 "홍길동"으로 정하자
틀"이름은 {'이름'의 '길이'}글자예요."를 출력하자
```

### 글자는 만들어진 뒤에 바꿀 수 없어요

글자의 몇 번째 글자만 슬쩍 바꾸는 것은 안 돼요.

```haja fail
'이름'을 [문자열]인 "홍길동"으로 정하자
'이름'의 1번째를 "김"으로 정하자
```

바꾸고 싶다면 원하는 모양의 **새 글자**를 만들어서 다시 담으세요.

```haja
'이름'을 [문자열]인 "홍길동"으로 정하자
'이름'을 [문자열]인 "김" + '이름'의 <자르기>(2, 3)로 정하자
'이름'을 출력하자
```

글자를 하나씩 꺼내서 다루는 방법은 [7장](/docs/tutorial/7-loops)에 있어요.
