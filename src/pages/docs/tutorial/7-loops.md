---

똑같은 코드를 백 번, 천 번 복사해서 붙여넣을 수는 없겠죠? 반복문을 사용하면 코드를 아주 간결하게 줄일 수 있어요.
가장 쉬운 '정해진 횟수만큼 반복하기'를 해볼까요?

```hari
1부터 3까지 반복하자 ('횟수'):
    틀"현재 횟수: {'횟수'}"를 출력하자
```

특정 조건이 만족되는 동안에만 계속 반복하게 만들 수도 있어요. `~인 동안 반복하자:` 구문으로 에너지가 다 떨어질 때까지 반복해볼게요!

```hari
'에너지'를 [숫자]인 3으로 정하자

('에너지'가 0보다 크다)인 동안 반복하자:
    틀"에너지 남음: {'에너지'}"를 출력하자
    '에너지'에서 1을 빼자
    
"에너지가 모두 소진되었습니다!"를 출력하자
```

배열(목록) 안에 들어있는 데이터들을 하나씩 꺼내면서 반복할 수도 있답니다. 아주 유용하게 쓰이는 방법이에요.

```hari
'과일들'을 [(문자열)목록]인 ["사과", "바나나", "포도"]로 정하자

'과일들'의 '과일'마다 반복하자:
    틀"맛있는 {'과일'}입니다!"를 출력하자
```

### 반복을 중간에 끝내기

`반복을 끝내자`를 만나면 가장 안쪽 반복문에서 바로 빠져나와요. 원하는 것을 찾았을 때 더 돌 필요가 없으니 편해요.

```hari
1부터 10까지 반복하자 ('수'):
    만약 ('수'가 4와 같다) 라면:
        반복을 끝내자
    틀"{'수'}번째 시도"를 출력하자
```

### 거꾸로 세기

시작 숫자가 끝 숫자보다 크면 하나씩 줄어들며 반복해요. 끝 숫자도 포함이라서 `3부터 1까지`는 3, 2, 1이에요.

```hari
3부터 1까지 반복하자 ('수'):
    '수'를 출력하자
"발사!"를 출력하자
```

### 글자를 하나씩 꺼내기

문자열도 목록처럼 `마다 반복하자`로 글자를 하나씩 꺼낼 수 있어요.

```hari
'인사'를 [문자열]인 "안녕"으로 정하자

'인사'의 '글자'마다 반복하자:
    틀"글자: {'글자'}"를 출력하자
```

### 반복 안에서 만든 변수와 밖의 변수

반복문은 **돌 때마다 새 공간**을 열어요. 반복 안에서 처음 만든 변수는 그 반복이 끝나면 사라지고, 반복 밖에서는 쓸 수 없어요.

```hari fail
1부터 2까지 반복하자 ('횟수'):
    '제곱'을 [숫자]인 ('횟수' * '횟수')로 정하자
'제곱'을 출력하자
```

반복이 끝난 뒤에도 값을 쓰고 싶다면 반복문 **앞에서** 변수를 만들어 두고, 안에서는 그 변수를 바꿔요.

```hari
'합'을 [숫자]인 0으로 정하자

1부터 4까지 반복하자 ('수'):
    '합'에 '수'를 더하자

틀"1부터 4까지의 합: {'합'}"을 출력하자
```

### 반복 중에 바꿔도 돌 횟수는 그대로

`1부터 10까지`처럼 숫자를 쓸 수도 있고, `1부터 '끝'까지`처럼 **변수나 식**을 끝값(시작값도)으로 쓸 수도 있어요.

반복이 시작될 때 돌 횟수가 정해져요. 끝값은 시작할 때 한 번만 읽으니까, 반복 안에서 `'끝'`을 바꿔도 돌 횟수는 그대로예요. 반복 안에서 `'횟수'` 같은 반복 변수를 바꾸면 **그 번의 값만** 달라지고, 다음 번에는 원래 세던 다음 숫자가 들어와요.

```hari
'끝'을 [숫자]인 3으로 정하자

1부터 '끝'까지 반복하자 ('횟수'):
    틀"{'횟수'}번째"를 출력하자
    '횟수'에 10을 더하자
    '끝'에 1을 더하자
```

`마다 반복하자`도 시작할 때의 목록을 그대로 돌아요. 반복 안에서 그 목록에 항목을 추가해도 새 항목은 돌지 않으니, 끝나지 않는 반복이 생기지 않아요.

```hari
'수들'을 [(숫자)목록]인 [1, 2, 3]으로 정하자

'수들'의 '수'마다 반복하자:
    '수들' 뒤에 '수'를 추가하자

틀"개수: {'수들'의 '길이'}"를 출력하자
```
