description: 똑같은 일을 여러 번 반복해봅시다.
---

똑같은 코드를 백 번, 천 번 복사해서 붙여넣을 수는 없겠죠? 반복문을 사용하면 코드를 아주 간결하게 줄일 수 있어요.
가장 쉬운 '정해진 횟수만큼 반복하기'를 해볼까요?

```haja
1부터 3까지 반복하자 ('횟수'):
    틀"현재 횟수: {'횟수'}"를 출력하자
```

특정 조건이 만족되는 동안에만 계속 반복하게 만들 수도 있어요. 에너지가 다 떨어질 때까지 반복해볼게요!

```haja
'에너지'를 [숫자]인 3으로 정하자

('에너지'가 0보다 크다)인 동안 반복하자:
    틀"에너지 남음: {'에너지'}"를 출력하자
    '에너지'에서 1을 빼자
    
"에너지가 모두 소진되었습니다!"를 출력하자
```

배열(목록) 안에 들어있는 데이터들을 하나씩 꺼내면서 반복할 수도 있답니다. 아주 유용하게 쓰이는 방법이에요.

```haja
'과일들'을 [목록]인 ["사과", "바나나", "포도"]로 정하자

'과일들'의 '과일'마다 반복하자:
    틀"맛있는 {'과일'}!"을 출력하자
```
